### Mini Projects

Small projects created using multiple C source files and functions.

#### Matrix Library

A simple matrix library in C supporting:

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Determinant of 2×2 and 3×3 matrices
- Matrix Transpose

The Matrix Library is organized using a header file and separate source files:

```text
Matrix-Library/
├── main.c
├── matrix.c
└── matrix.h
```
